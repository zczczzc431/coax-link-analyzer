# 功能状态与已知问题

状态日期：2026-11-03。历史实测、当前故障和离线候选分别说明。

## 已完成的主要软件工作

- SCOPE 波形显示、触发配置、时基/垂直交互、游标、统计与质量提示。
- FFT 频谱显示、峰值与窗口幅度处理；区分 FFT 栅格与窗口 ENBW。
- MONITOR 参考学习、幅度/频率异常、频谱 MASK、事件统计和关键帧回查。
- 异步证据存储、完整性校验、索引持久化、错误处理和退出保存。
- SWEEP 参考曲线与相对传输变化分析。
- 耦合器 Forward/Reverse 两阶段手动 REFLECT 流程、相关计算与导出。
- 699 r2 恢复 HOLD 10–5000 ms 配置、界面与报告同步，具有历史实板及冷启动验收记录。

这些历史结果不表示所有板卡组合现在都运行正常。开源 CI 仅证明它实际执行的编译和回归。

## 当前 DAC 故障

更换同型号载板/子卡后，独立外部源验证接收功能可用，但 DAC 的目标输出异常。历史独立仪器反馈为 OUT1 约 100 MHz、0.6 Vpp、50 Ω，包括请求 OFF 时；信号来源尚未证明。

最小诊断在同一 SPI 引擎下正确读到 AD9516 ID `0x43`，并观察到标称 200 MHz ADC DCO；DAC 身份/版本回读却不可信，出现地址末位跟随或全 `0xFF`。正式初始化停在等待 DAC `0x16[7]` PLL 锁定位，`init_done=0`。不带事务完成标志的调试数据不能当作有效寄存器读数。

读写降速、位序对照、有限软件复位、FMC 重插和完整旧系统文件恢复未解决问题。没有证明载板或子卡损坏，也没有证明 DAC REF/DACCLK/DCI 都正确。当前停止修复，不再以重复刷卡代替定位。

原始 SPI 代码还存在仿真中可见的位宽绑定与读换向问题；修复候选仍未解除实板故障。因此不能宣称“原程序完全无缺陷”。授权不明的厂商 SPI 源码不在本次发布范围。

## 尚未完成

**AWG**：软件公式、Q15 波形包、CRC、预览和保护事务已有工作；不能把页面存在或软件回归通过称作任意波形模拟输出已验收。

**1 kHz RBW**：DDC、滤波、抽取与冻结缓存有隔离回归和 OOC 时序结果。后续整机候选曾出现控制路径未接通、读回合同偏移以及 200/400 MSPS DAC 合同错配。即使有效帧长度正确，也未通过真实峰值与幅度验收。本仓库保留 765 为隔离实验，不发布失败整机位流。

**高频 MASK**：并非所有频段都可成功参考学习；频段、背景噪声、可检测下限与稳定性资格仍需按实际信号条件核验。拒绝学习不应以降低门槛掩盖。

**DTF/FDR**：没有验收为有效故障距离测量；页面或数学模块不能等同于可用测距仪。

## 指标的正确含义

- ADC 为标称 14 bit / 400 MSPS；这不是整机 ENOB 或绝对电压精度。
- 2048 点、400 MSPS 的 FFT 栅格为 195.3125 kHz；对称 Hann 窗 ENBW 约 293.1 kHz。不能将更细的频率数字读数叫作 1 Hz RBW。
- 标称时钟下的细频率估计不等于经校准的绝对准确度；没有可追溯外部参考，不承诺 ppm。
- HOLD 10 ms 是信号恢复后的持续正常保持设置，不保证捕获所有 1–10 ms 异常。
- REFLECT 为相对、分时的标量测量流程，不承诺商业 VNA 的校准精度、动态范围或距离定位能力。
