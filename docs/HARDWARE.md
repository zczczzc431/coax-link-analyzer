# 硬件与接口

## 开发平台

| 部分 | 平台与作用 |
|---|---|
| 处理平台 | Z20，XC7Z020CLG484-2，PS Linux 与 PL 协同 |
| FMC 子卡 | FMCADDA-5474-9142，具体 PCB 修订需核对 |
| 接收 | ADS5474，标称 14 bit / 400 MSPS |
| 发射 | AD9142A，数字数据通路与插值/采样时钟必须配套 |
| 时钟 | AD9516-3，多路时钟分配与配置 |
| 显示交互 | 800×480 framebuffer LCD 与 Linux input 触控接口 |
| 外部链路 | 50 Ω 同轴线、适当衰减器；反射模式另需定向耦合器和匹配终端 |

项目的帧接口采用每 200 MHz 周期两个按时间排序的样点，表示标称 400 MSPS。不能混用旧 200 MSPS 单样点发生器与 400 MSPS FTW 控制工具。

## 电气前提

本项目实际 FMC 数字接口使用 2.5 V I/O 配置，Bank33/Bank34 供电必须与准确板卡资料和 XDC 一致。跳线位置需按厂商对应 PCB 版本确认，禁止通电移动跳线。DAC 芯片内部电源与 FPGA I/O 电平不能混为一谈。

ADC 输入范围、耦合、端接、偏置及允许功率以厂商子卡资料为准；源码中的百分比为数字幅度，不是校准后的端口电压。不要以杜邦线和极低幅度信号评估射频信号质量。外部源与板上 GEN 输出不能并接。

## 板级集成需另行取得

- 对应载板与 FMC 子卡原理图、管脚约束及修订信息。
- PS DDR、LCD framebuffer、触控、AXI BRAM/GPIO 与复位的 Vivado BD/IP 配置。
- SelectIO、时钟原语及初始化 SPI 例程的合法来源与许可证。
- 匹配的 U-Boot/Linux/设备树和 framebuffer/input 驱动。

本仓库的 ADC 模块是数据通路组件，未声明它们与历史稳定位流逐网表相同。DAC400 是历史参考，不含所有后续 ROM ECO。不能凭相同板卡型号或绿色 PLL 灯判定整个链路可用。

## 集成操作边界

不要在 Linux/LCD 正运行时通过 JTAG 重配置整片 PL；项目曾因此出现系统卡住和黑屏。临时整机测试须先独立审查启动前加载、恢复镜像与关机流程。本仓库不提供自动执行这些动作的脚本，也不修改设备 SD。
